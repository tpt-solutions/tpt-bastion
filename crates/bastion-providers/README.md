# bastion-providers

The provider plugin system for [TPT Bastion](https://bastion.tpt.dev), implementing
Phase 5 of the roadmap: a provider SDK/ABI, a capability schema format, a
pluggable runtime (in-process and isolated subprocess), a registry, and
scaffolding.

See `docs/provider-guide.md` for the developer guide and
`crates/bastion-providers/src/lib.rs` for the module layout.
