# bastion-events

Event-driven reconciliation for TPT Bastion: a pluggable `EventSource` model
(`FileEventSource`, `WebhookEventSource`) and a `run_forever` reconcile loop.

See [`docs/events.md`](../../docs/events.md) for the design and the `bastion
events` CLI subcommand.
